Advanced settings

QLIC runs in WebAssembly in this browser; this is offline and nothing leaves your device. Image input is rendered to RGBA8. RGBA8 QLIC files keep animation and hidden RGB when exported to a PNG. Wide and HDR files use a labeled 8-bit SDR preview instead. Use the API or native app if you need exact samples.
